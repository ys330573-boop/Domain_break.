## Animations

- Clips with `quaternius` in the name (`sprint_exit`, `backflip`, `melee_combo`,
  `melee_uppercut`, `kipup`, `sprint_loop`): from the Quaternius animation
  library — https://quaternius.com
- Other clips (`walk_relaxed`, `kick_jump`, `kick_spinning`, `punch_cross`,
  `punch_hook_left`, `aerial_roundhouse`, `aerial_spin_slash`,
  `karate_chop_overhead`, `celebrate_arms_wide`, `idle_sit_relaxed`,
  `combo_jab_cross_hook`, `aerial_dive_kick`, `sonic_strike`, `kick_side`,
  `idle_impatient`, `fidget_arm_stretch`): added by the auto-rigging tool used
  to rig the models, under that tool's terms.
- Toji's pistol is a simple built-in prop drawn by the game code (`src/weapons.js`).
